# @bizcity/twin-ui-sdk

TypeScript SDK for BizCity Twin extension contracts.

## Includes

- Manifest types with permission and security fields.
- Capability descriptor types for tools, skills, agents, channels, KG adapters, workflow blocks, personas, and output renderers.
- Shape guard helper: isManifestShape.

## Scripts

- npm run build
- npm run test:contracts

## Public Contract Catalog

Schemas and fixtures are defined in:

- core/twin-core/contracts/schema/public/v1

Run contract tests:

- node core/twin-core/contracts/tests/run-contract-tests.mjs
